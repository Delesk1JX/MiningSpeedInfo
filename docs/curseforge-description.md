Shows the real mining speed of digging tools in their tooltip. Minecraft never shows this number, which is why it gets mixed up with attack speed.

## What it does

*   Mining speed for pickaxes, axes, shovels and hoes
*   Harvest level, so you can see which blocks a tool can break: `0` mines stone, `1` iron ore, `2` diamonds, `3` obsidian, `4` ancient debris
*   Counts the Efficiency bonus the way vanilla does, so an Efficiency V iron pickaxe reads `32` instead of `6`, or `32 (+26)` if you prefer the bonus spelled out
*   Adds both values to Quark's attribute tooltip, right behind the values Quark shows itself, with the same up and down arrows, so you can see at a glance if the hovered tool is faster or slower than the one in your hand
*   Holding sneak shows the plain lines with the full names instead, the same way the rest of the tooltip works
*   Swords, shears and other non-tools are left alone unless you ask for them
*   Settings screen with its own keybind: colour, decimals, sneak only, Quark values, comparison arrows
